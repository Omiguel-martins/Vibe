# VIBE · Perfumaria Premium

E-commerce PWA de alta perfumaria construído com React, Vite, Tailwind CSS e integrado ao Supabase.

## ✨ Produtos Oficiais
- **VIBE · Boa Menina** (200ml) — Oriental Floral
- **VIBE · Rosa da Manhã** (200ml) — Floral Fresco
- **VIBE · Invencível** (200ml) — Amadeirado Aquático
- **VIBE · Combo Coleção Completa** (3x 200ml)

## 🚀 Como Rodar Localmente
```bash
npm install
npm run dev
```

## 📦 Build para Produção
```bash
npm run build
```
